# Security

Please report a vulnerability privately through
[GitHub's security advisories](https://github.com/tbgihu/orbit/security/advisories/new), not in a public issue.
Include what you found, how to reproduce it, and the commit you tested.

Orbit runs the commands in your `orbits.json` with your user's rights. Treat an orbit entry someone sends you like
any shell command: read it before you add it.
